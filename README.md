# 💕 About Saheli

### *A little more than a chatbot...*

</div>

**Saheli AI** is an emotionally intelligent personal AI companion designed to make AI interaction feel more natural, personal and alive.

Saheli combines conversation, memory, voice, vision, real-time awareness, music, reminders, image generation and an interactive cinematic character into one personal AI experience.

She can communicate naturally in **Hinglish, Hindi and English**, remember useful context, react to interactions, understand the current environment and appear as a visual companion.

```text
💬 Conversation
🧠 Long-Term Memory
🎙️ Voice
👀 Vision
🌤️ Real-Time Awareness
🎭 AI Companion
📸 AI Image Generation
🎵 Music
⏰ Smart Reminders
🎨 Deep Personalization
```

### **She exists inside the experience. 💗**

The environment changes according to real-world conditions.


# 🚀 Getting Started

### 01 — Clone

```bash
git clone https://github.com/Alakhx-dev/Saheli-Ai-Assistant.git

cd Saheli-Ai-Assistant
```

### 02 — Install

```bash
npm install
```

or

```bash
bun install
```

### 03 — Configure Environment

```bash
cp .env.example .env
```

Add the required credentials to `.env`.

### 04 — Run

```bash
npm run dev -- --host
```

Open:

```text
http://localhost:5173
```

# 🔐 API Credentials

Saheli integrates multiple AI, cloud, voice, music and image-generation services.

| Provider         | Credential Needed            | Used For              |
| :--------------- | :--------------------------- | :-------------------- |
| 🤖 Groq          | API Key                      | AI + Whisper          |
| ✨ Gemini         | API Key                      | AI + Image Generation |
| 🔀 OpenRouter    | API Key                      | AI / Model Routing    |
| ☁️ AWS           | Access Key + Secret + Region | Voice / AWS Services  |
| 🎵 JioSaavn      | API / Service Configuration  | Music                 |
| 🌐 Cloudflare    | API Token / Key              | Image Infrastructure  |
| 🎨 Diffusion API | API Key                      | Image Generation      |
| 🔥 Firebase      | Firebase Configuration       | Auth + Memory         |

### Example `.env`

```env
VITE_GROQ_API_KEY=your_groq_api_key

VITE_GEMINI_API_KEY=your_gemini_api_key

VITE_OPENROUTER_API_KEY=your_openrouter_api_key

AWS_ACCESS_KEY_ID=your_aws_access_key

AWS_SECRET_ACCESS_KEY=your_aws_secret_key

AWS_REGION=your_aws_region

VITE_CLOUDFLARE_API_KEY=your_cloudflare_key

VITE_DIFFUSION_API_KEY=your_diffusion_api_key

# Firebase
VITE_FIREBASE_API_KEY=your_firebase_key
VITE_FIREBASE_AUTH_DOMAIN=your_firebase_domain
VITE_FIREBASE_PROJECT_ID=your_firebase_project
```

> ⚠️ Use the exact environment-variable names required by your implementation.

> 🔐 **Never commit private API credentials or `.env` files to GitHub.**
